## 3. 功能验证

### 3.1 应用间跳转拦截（核心）

| 场景 | 触发方式 | 结果 |
|---|---|---|
| 静默跳转 A→B | `am start` B（无用户操作） | 弹窗"静默跳转拦截 · 无用户操作 / 跳转测试A → 敏感界面B"，5 秒倒计时 |
| 倒计时超时 | 不操作 | 自动执行 BACK 撤回，记录 `verdict=block` |
| 仅本次允许 | 点"仅本次" | 放行，记录 `verdict=allow` |
| 真实场景 | 浏览器自动唤起"通知管理" | 弹窗"应用间跳转确认"，被阻止 |
| 真实场景 | 微信输入法 / 智能侧边栏 → 浏览器 | 均被判定并阻止 |

事件库实测记录（节选）：

```

jump  应用安装器 → 敏感界面B          block  high
jump  应用安装器 → 敏感界面B（本次允许）allow  warn
jump  浏览器 → 通知管理               block  high
jump  智能侧边栏 → 浏览器             block  high
jump  微信输入法 → 浏览器             block  high
```

### 3.2 屏幕内容敏感扫描

界面 B 显示假身份证 / 银行卡 / 手机号 / 验证码 / 邮箱，实测产出：

```

collusion 敏感界面与潜在读屏通道并存：敏感界面B                                                  alert warn
```

- 脱敏正确（首尾保留、中间打码）
- 身份证 / 银行卡因演示号码未通过校验位 / Luhn，被标为"疑似"（`level=warn`）；真实号码为强命中（`level=high`）

# 第四轮：集成开屏跳过（v2.1.0）

参考对象：`rongzhiy/LiTiaotiao`（李跳跳分发仓库，无源码），按同等能力自研。

## 机制

- 触发：应用窗口首次出现后 5 秒内，最多 5 次尝试（200ms 起，间隔 600ms）
- 候选条件（必须同时满足）：
  1. 文本/描述命中 `跳过 / skip / 关闭广告 / X` 等关键词，且长度 ≤ 12
  2. 不包含危险词（支付/确认/删除/卸载/授权/购买/订阅…）
  3. 尺寸不超过屏宽 35%、屏高 10%
  4. 位置位于上方右侧（x>55% 且 y<30%）或底部小控件
- 打分排序：含"跳过"+1.2 / 右上 +0.9 / 小尺寸 +0.5 / 大面积 −1.2
- 成功点击后 1.5 秒冷却，同一控件（文本+位置）不重复点击
- 点击动作**不计入用户交互**，不影响跳转守卫的静默判定

## 实测

| 项 | 结果 |
|---|---|
| 模拟启动页（右上「跳过 5S」按钮） | 自动点击成功，日志 `LSANTEST: skip-clicked` |
| 防重复 | 加入 1.5s 冷却后单次启动只点一次 |
| 误伤防护 | 危险词与大尺寸控件被排除；实测未点击主内容按钮 |

## 同时修复

- **系统入口放行**：源为桌面/侧边栏/通知栏等系统 UI 时视为用户主动启动，不再弹拦截确认（此前从 realme 智能侧边栏启动应用会被误拦）
- 快捷开关默认值改为读取模块定义（此前硬编码为开，与模块实际状态不一致）
